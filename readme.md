# Our Moon
Live demo: https://danielluzhu.github.io/our-moon/

Tables run with no server behind them on that link, so answers stay in the
browser you open it in and a table cannot actually be shared. Run `bun run dev`
for the real thing.

**In person mode** is the exception: everyone is in the same room, so there is
nothing to join and nothing to send anywhere. It needs no server by design, which
makes it the real thing on the link above rather than a demo.

I want to build a webapp for families, who all live in different cities, to be able to share conversations together. Eventually this will be phone app - this is proof of concept 

Users (family members) can share a table (family unit) and all respond to the same topic. They are expected to share 20s - 1 minute stories. 

The topics can be a range of things, from fun to serious to intimate. 

Create a file that is a list of all the prompts. Questions should meet following criteria:
- positive and not force vulnerability (even intimate questions can have a decent alternative). 
- majority of questions should be fun or light hearted, this is a place for people to enjoy.
- not require too much shared context to answer 
- avoid yes/no questions, hedge towards stories 

The questions should generally fall into the following categories:
Some slice of life examples: 
- what is one of your favorite things at home? 
- what is something recently you've been obsessed with? 
- what is a favorite product of yours? 


Some story times: 
- Tell us about a time you got completely lost
- what is something you hid a long time ago and never had a chance to share 
- a moment with someone else at the table you keep rethinking of 
- a time you were really proud of 
- Tell us about a time you got completely lost

fun banter: 
- which animal do you think <certain family member> is? 
- what is something you are looking forward to? 

Some intimate examples:
- what is something from the past that you enjoy thinking of? 
- share a favorite moment of yours this year 
- something you learned from someone at this table
